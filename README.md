# Retail Sales Data Analysis with Seasonal Trends & Marketing Insights

**Tools:** Python · Pandas · NumPy · Matplotlib · Jupyter Notebook · SQLite/SQLAlchemy · Power BI

## 📌 Project Overview
An end-to-end data analytics workflow — from raw retail transaction data to a Power BI dashboard. Covers data cleaning, exploratory data analysis (EDA), feature engineering, and business insight generation in Python, with the processed output feeding into a Power BI dashboard for reporting.

## 🗂️ What I Built
- Loaded raw retail sales records and performed **data cleaning**: removed null values, standardized column types
- Used **Pandas** to filter, group, and aggregate transactional data; used **NumPy** for numeric operations
- Performed **exploratory data analysis (EDA)** and basic visualizations with **Matplotlib**
- Calculated **group-level summary metrics** — total revenue, average order value, and category counts across product categories
- Integrated **SQLite/SQLAlchemy** to run SQL queries directly inside Python, bridging programmatic and SQL-based analysis
- Fed the cleaned, processed dataset into **Power BI** to build a dashboard for business reporting
